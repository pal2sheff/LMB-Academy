# Первое задание для Claude Code

Скопируйте этот текст в первую сессию, открытую в распакованной папке проекта.

```text
Продолжи разработку LMB Академии по LMB_TZ.md. Сначала прочитай CLAUDE.md, BASELINE.md и modules.json, затем изучи текущий прототип в site/.

Нужно сохранить все 14 направлений, существующие тексты и маршруты. Главная задача первого этапа: сделать удобную учебную базу с врачебными саммари, будущей выжимкой для администраторов и простым добавлением подготовленных материалов через файлы.

Содержание готовим в ChatGPT вместе с главным врачом. Ты подключаешь текстовые пакеты к сайту, развиваешь интерфейс и реализуешь правила проверки и сборки. Не меняй медицинский смысл при переносе. Отсутствующие лекции и недостающие данные не выдумывай.

Проведи аудит и локальный запуск. Затем выполни этапы А–Д из ТЗ: раздели данные и интерфейс, создай структуру тем и версий, локальный предпросмотр, проверку источников и утверждения текста, производственную сборку без черновиков и приватных файлов. Подготовь инструкцию по добавлению одной новой темы и обновлению существующей.

Начни с текущего HTML/CSS/JavaScript. Не подключай платные сервисы, внешний ИИ или новый хостинг автоматически. Недостающие медицинские материалы перечисли по темам, продолжая независимую техническую работу.
```

Полные учебные исходники в этом архиве отсутствуют. Когда они понадобятся для содержания, передадим отдельный пакет по выбранной теме.
