# Учебный пакет темы

Один пакет — одна тема и один вариант аудитории. Для администраторов те же файлы с префиксом `admins.` вместо `doctors.`. Все блоки, кроме основного текста, необязательны: незаполненный блок на сайте не показывается.

## Куда что положить

| Что | Файл | Поле в `metadata.json` → `variants.doctors` |
| --- | --- | --- |
| Основной материал | `content/lessons/<тема>/doctors.md` | `"body": "doctors.md"` (уже есть) |
| Введение | `content/lessons/<тема>/doctors.intro.md` | `"intro": "doctors.intro.md"` |
| За 2 минуты | `content/lessons/<тема>/doctors.brief.md` | `"brief": "doctors.brief.md"` |
| Главная инфографика | `content/media/<тема>/main.png` | `"infographic": {"src": "main.png", "alt": "…", "caption": "…", "description": "…"}` |
| Дополнительный рисунок | `content/media/<тема>/scheme-1.png` | не нужно: строка в тексте `![описание](scheme-1.png "Подпись")` |
| Видео и ссылки | — | `"media": [{"title": "…", "url": "https://…", "note": "…", "duration": "12:30"}]` |
| Игра | папка `content/games/<тема>/doctors/` с `index.html` | `"game": {"title": "…", "description": "…"}` |
| Проверка знаний | `content/lessons/<тема>/doctors.quiz.json` | `"quiz": "doctors.quiz.json"` |

Пример полей — `metadata.example.json`, пример теста — `doctors.quiz.example.json`.

## Правила

- Рисунок вставляется отдельной строкой в нужном месте текста; `описание` обязательно (для экранных чтецов). Форматы: PNG, JPG, WEBP, GIF, SVG без сценариев. Размер — до 3 МБ; ширина 1600–2400 px для схем.
- Ссылки только `https://`, без паролей, токенов и ключей доступа. YouTube показывается кнопкой «Смотреть» и ссылкой «Открыть на YouTube»; облачные диски — обычной ссылкой. Доступ к закрытым папкам настраивает владелец диска.
- Тест: ровно 5 вопросов, у каждого 2–6 вариантов, `answer` — номер правильного варианта с нуля, короткое `explanation`. При существенном изменении вопросов увеличьте `version`, чтобы сотрудники прошли тест заново; правка опечатки версию не меняет.
- Введение, выжимка, тест, описания иллюстраций, видео и сами изображения входят в контрольную сумму: после любого изменения нужно новое утверждение.

## Игра

Порядок блоков на странице: введение → основной материал → за 2 минуты → инфографика (и рисунки в тексте) → видео и ссылки → **игра** → проверка знаний.

1. Игра — самостоятельная страница: `content/games/<тема>/doctors/index.html` (для администраторов — `…/admins/`). Рядом можно положить её `.js`, `.css`, `.json`, картинки (`.png`, `.jpg`, `.webp`, `.gif`, `.svg`) и шрифты `.woff2`. Другие типы файлов не допускаются.
2. В `metadata.json` варианта: `"game": {"title": "Цепочка стероидогенеза", "description": "Соберите этапы по порядку"}`. Необязательно `"entry": "start.html"`, если файл запуска называется иначе.
3. На странице появляются название, описание и кнопка «Начать игру». Игра открывается внутри страницы; кнопка «Развернуть» раскрывает её на весь экран (Esc — свернуть), «Закрыть игру» возвращает к материалу.
4. Игра работает в изолированном окне: ей доступны только собственные сценарии. Она не видит данные сайта, не сохраняет прогресс в браузере и не влияет на тест и отметку «Пройдено». Всё нужное — в её папке, без загрузки с внешних серверов и без всплывающих окон.
5. Делайте управление нажатиями, а не только перетаскиванием: так удобнее на телефоне. Ширина от 320 px, кнопки не меньше 44 px по высоте.
6. Стартовый шаблон «собери цепочку по порядку» — `templates/game_template/index.html`: замените заголовок, задание и шаги в объекте `GAME`.
7. Файлы игры входят в контрольную сумму: после изменения игры тему утверждают заново. Пока поле `game` не заполнено, блок и ссылка «Игра» не показываются.

## Проверка

```bash
python scripts/lmb.py check
python scripts/lmb.py status
python scripts/lmb.py preview
python scripts/lmb.py serve preview
```

`status` перечисляет незаполненные блоки каждой темы. Пример полностью заполненной темы без медицинского содержания: `python scripts/lmb.py demo`, затем `python scripts/lmb.py serve demo`.
