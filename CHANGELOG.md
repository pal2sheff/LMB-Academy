# Журнал изменений

## 0.6.0 — 15.10.2026

- Блок «Игра» между «Видео и ссылки» и «Проверкой знаний»: название, описание, «Начать игру»; игра открывается внутри страницы, «Развернуть» — на весь экран (Esc — свернуть), «Закрыть игру».
- Игра — самостоятельный модуль `content/games/<тема>/<вариант>/index.html` в iframe с `sandbox="allow-scripts"`: без доступа к данным сайта, тесту и прогрессу. Отдельные игры для врачей и администраторов.
- Проверка папки игры (файл запуска, допустимые типы, предупреждение о внешних ресурсах); файлы игры входят в контрольную сумму; в сборку попадают только игры опубликованных вариантов.
- Без поля `game` блок и ссылка «Игра» скрыты; прежние темы не изменились. В однофайловой версии игры не подключаются.
- Стартовый шаблон игры `templates/game_template/index.html` («собери цепочку»), нейтральная демо-игра в фикстуре, 2 новых теста.

## 0.5.0 — 15.10.2026

По `LMB_Learning.md`: шаблон учебной темы без нового медицинского содержания.

- Необязательные блоки темы для каждого варианта аудитории: введение (`intro`), «За 2 минуты» (`brief`), главная инфографика (`infographic`), дополнительные рисунки в Markdown (`![описание](файл "подпись")`), видео и ссылки (`media`), тест из 5 вопросов (`quiz`). Пустые блоки и якоря на них скрыты.
- Иллюстрации — в `content/media/<тема>/`; сборка копирует только используемые; увеличение в диалоге с возвратом фокуса; SVG без сценариев.
- YouTube встраивается после «Смотреть» (youtube-nocookie, ID проверяется), рядом всегда исходная ссылка; остальные адреса — обычные ссылки; запрет http, паролей и токенов в ссылках.
- Тест: проверка, пояснения, «Пройдено» при 4 из 5, повтор без ограничений, лучший результат не стирается, «Тест обновлён» при новой версии. Прогресс «Пройдено X из Y тем» по опубликованным темам с тестом; хранение в `lmb-academy-quiz-v1`, отдельно от «Прочитано».
- Контрольная сумма включает новые блоки и хеши иллюстраций; суммы тем без пакета не изменились; снимок `approve` хранит тексты пакета.
- `lmb.py demo` — локальная демонстрация на нейтральной фикстуре `tests/fixtures/demo-lesson` (в `demo/`, не публикуется); `status` показывает незаполненные блоки.
- Шаблон пакета `templates/lesson_package/`; 7 новых тестов.

## 0.4.0 — 15.10.2026

По `LMB_Audit_v2.md`.

- Новое направление 15 «Стероидный профиль в слюне» (`steroid-saliva`, тема `steroid-saliva-intro`): программа из 10 тем, `outline`/`draft` 0.1.0, без утверждения; связанные темы — гормональная терапия, мужское и женское здоровье, пеллеты, метаболиты эстрогенов. Отдельная группа синонимов.
- Три группы: «Диагностика» (6), «Вмешательства» (6), «Основы и клинические направления» (3). Поля `category`, `displayOrder`, новые ключи `icon`; проверки группы, порядка и иконки в `lmb.py check`.
- Каталог, меню и поиск используют одну группировку; фильтр группы доступен по ссылке `#group/<id>`; путь на странице материала ведёт к группе.
- Встроенные контурные SVG-иконки (15 + нейтральная) в карточках, меню, поиске и у заголовка материала.
- Готовящиеся темы и программы показываются компактно: метка «Готовится», одно предложение, «Программа», связанные темы.
- Редакторские разделы исключаются из учебного представления через `editorialSections` (Markdown не изменён); версии затронутых тем подняты на PATCH.
- «Назад / Далее» — внутри направления и группы; на границе группы — «К направлениям».
- Тесты: обязательное направление и группы, проверка группы, добавление следующего направления без фиксированного числа, скрытие редакторских разделов.

## 0.3.0 — 14.10.2026

Редактура интерфейса по `LMB_UI_Fixes.md`.

- Удалены: лозунги шапки и боковой панели, монограмма, вводный блок главной со счётчиками и панелью «Первый этап», баннер предпросмотра, отчёт о наполнении, рекламный вводный блок для администраторов, пояснения о черновике, о программе раздела, о хранении отметок и о прослеживаемости источников, дата сборки в подвале.
- Главная: переключатель «Врачам / Администраторам», «Направления», поиск, фильтры, компактный список в две колонки. Счётчик только при поиске.
- Направление с одной темой открывается сразу темой (каталог, меню, старый маршрут `#module/<id>`); у озонотерапии остаётся список из пяти тем.
- Тема: путь, название, одна метка, подзаголовок границы содержания, дата; «Главное» обычным абзацем; содержание справа или свёрнутое на телефоне; внизу «Источники», «О материале», отметка прочтения, соседние материалы.
- Статусы: «Проверено», «Черновик», «Готовится», «Недоступно»; итог направления — «Готовится», «Черновик», «Есть материалы», «Материалы и черновики».
- Стиль: системный шрифт, шапка 60/56 px, без декоративных иконок, номеров, теней и подъёма карточек; нумерация разделов убрана.
- Источники: читаемые названия; исходные имена файлов перенесены в закрытый реестр.
- Шесть черновиков: добавлен `subtitle`, версия 0.1.1 (PATCH; Markdown не изменялся). `subtitle` включён в контрольную сумму.
- Подписи вариантов: «Врачам», «Администраторам». Якоря разделов добавляются в историю браузера.

## 0.2.0 — 14.10.2026

Этапы А–Д первого этапа (см. `docs/AUDIT_AND_PLAN.md`).

### Содержание
- Тексты 14 направлений перенесены из `site/content.js` в `content/lessons/<id>/doctors.md` дословно; все получили `editorialStatus: draft`.
- Добавлены темы озонотерапии: внутривенный раствор, БАГОТ, ректальные и вагинальные инсуффляции (статус «Материал готовится»).

### Интерфейс
- Направление → темы → два варианта обучения с независимыми статусами.
- Маршруты: `#lesson/<id>`, `#admins/...`, якоря разделов `#lesson/<id>/section-N`; старые `#module/<id>` и `#admins` работают.
- Поиск по темам с е/ё, синонимами и сокращениями; учитывает выбранный вариант и категорию.
- Отметки «Прочитано» привязаны к версии; отметки прототипа перенесены.
- Крупнее основной текст, читаемая длина строки, статусы со значком и текстом, печать без меню, кнопка «Распечатать».
- Пометки «Черновик», «Программа раздела», «Проверено», «требует сверки», «Снято с публикации».

### Инструменты
- `scripts/lmb.py`: `check`, `status`, `build`, `preview`, `serve`, `new-lesson`, `checksum`, `approve`.
- `tests/test_pipeline.py`: 20 проверок по критериям A01–A11.
- `legacy/prototype-1bdedd4/` — исходный прототип без изменений; `site/content.js` удалён из интерфейса.
