# Журнал изменений

## 0.3.0 — 14.10.2026

Редактура интерфейса по `LMB_UI_Fixes.md`.

- Удалены: лозунги шапки и боковой панели, монограмма, вводный блок главной со счётчиками и панелью «Первый этап», баннер предпросмотра, отчёт о наполнении, рекламный вводный блок для администраторов, пояснения о черновике, о программе раздела, о хранении отметок и о прослеживаемости источников, дата сборки в подвале.
- Главная: переключатель «Врачам / Администраторам», «Направления», поиск, фильтры, компактный список в две колонки. Счётчик только при поиске.
- Направление с одной темой открывается сразу темой (каталог, меню, старый маршрут `#module/<id>`); у озонотерапии остаётся список из пяти тем.
- Тема: путь, название, одна метка, подзаголовок границы содержания, дата; «Главное» обычным абзацем; содержание справа или свёрнутое на телефоне; внизу «Источники», «О материале», отметка прочтения, соседние материалы.
- Статусы: «Проверено», «Черновик», «Готовится», «Недоступно»; итог направления — «Готовится», «Черновик», «Есть материалы», «Материалы и черновики».
- Стиль: системный шрифт, шапка 60/56 px, без декоративных иконок, номеров, теней и подъёма карточек; нумерация разделов убрана.
- Источники: читаемые названия; исходные имена файлов перенесены в закрытый реестр.
- Шесть черновиков: добавлен `subtitle`, версия 0.1.1 (PATCH; Markdown не изменялся). `subtitle` включён в контрольную сумму.
- Подписи вариантов: «Врачам», «Администраторам». Якоря разделов добавляются в историю браузера.

## 0.2.0 — 14.10.2026

Этапы А–Д первого этапа (см. `docs/AUDIT_AND_PLAN.md`).

### Содержание
- Тексты 14 направлений перенесены из `site/content.js` в `content/lessons/<id>/doctors.md` дословно; все получили `editorialStatus: draft`.
- Добавлены темы озонотерапии: внутривенный раствор, БАГОТ, ректальные и вагинальные инсуффляции (статус «Материал готовится»).
- Публичный реестр источников `content/sources/public.json`; две ссылки на один DOI объединены.
- Словарь поисковых синонимов `content/synonyms.json`.

### Интерфейс
- Направление → темы → два варианта обучения с независимыми статусами.
- Маршруты: `#lesson/<id>`, `#admins/...`, якоря разделов `#lesson/<id>/section-N`; старые `#module/<id>` и `#admins` работают.
- Поиск по темам с е/ё, синонимами и сокращениями; учитывает выбранный вариант и категорию.
- Отметки «Прочитано» привязаны к версии; отметки прототипа перенесены.
- Крупнее основной текст, читаемая длина строки, статусы со значком и текстом, печать без меню, кнопка «Распечатать».
- Пометки «Черновик», «Программа раздела», «Проверено», «требует сверки», «Снято с публикации».

### Инструменты
- `scripts/lmb.py`: `check`, `status`, `build`, `preview`, `serve`, `new-lesson`, `checksum`, `approve`.
- `tests/test_pipeline.py`: 20 проверок по критериям A01–A11.
- `legacy/prototype-1bdedd4/` — исходный прототип без изменений; `site/content.js` удалён из интерфейса.
