# Исходное состояние проекта

Дата передачи 14 октября 2026 года.

В `site/` находится экспорт текущего статического прототипа LMB Академии. Он работает на HTML, CSS и JavaScript без сборщика. `content.js` хранит 14 направлений: шесть предварительных саммари и восемь структур. `app.js` реализует каталог, фильтры, поиск, страницы материалов, навигацию и локальные отметки прочтения. `styles.css` содержит адаптивное оформление.

Врачебный трек наполнен частично. В административном треке только описание следующего этапа и список направлений. Учёт сотрудников, серверная авторизация, онлайн-загрузка исходников, медицинское утверждение и управление версиями в текущем коде не реализованы.

При подготовке текущего прототипа проверены синтаксис JavaScript и сценарии маршрутов, поиска, счётчиков и переключения треков в программной среде. Полноценная визуальная браузерная проверка не выполнена. На доработке нужно провести реальную проверку на компьютере и телефоне.

Полные учебные материалы и медицинские документы пациентов в комплект не включены. В `source_inventory.csv` перечислено, какие источники упоминались в подготовке и что нужно получить. Статус источника в этой таблице относится к передаче файлов, а не к его медицинскому утверждению.

Служебная конфигурация размещения, учётные данные и каталог Git не экспортированы. Открытие `site/index.html` позволяет увидеть базовый интерфейс; для проверки маршрутов и сетевых запросов разработчик должен использовать локальный сервер. Готовый новый конвейер из ТЗ ещё предстоит реализовать.

Текущий сайт закрыт. Экспорт не даёт доступа к его управлению и не требует автоматического переноса на новую площадку.
